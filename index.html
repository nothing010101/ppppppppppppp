MusterMarket — Upgrade

Upgrade proxy V1 ke V2 (experimental). Alur: hubungkan wallet → deploy implementation V2 → Schedule Upgrade → tunggu 1 menit → Execute Upgrade.

Penting — baca dulu:
  • Buka halaman ini di browser dalam aplikasi MetaMask (Android) supaya wallet terdeteksi. Di browser biasa (Chrome) wallet tidak akan terdeteksi.
  • Hanya owner proxy yang bisa upgrade. Pastikan wallet yang terhubung adalah owner.
  • Upgrade itu 2 transaksi: Schedule, lalu Execute setelah timelock 1 menit.
  • V2 menghapus cancelListing / cancelBid / cancelOffer dan menambah sweep() — semua BNB di kontrak akan bisa di-sweep owner ke alamat hardcoded. Ini eksperimen, jangan pakai di mainnet dengan dana asli.
